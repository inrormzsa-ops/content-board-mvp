# Content Board MVP

Минимальная веб-доска для управления контентом по стадиям:

1. Идея
2. Черновик
3. Запланировано
4. Опубликовано

## Что входит

- Добавление новой идеи через кнопку `+ Идея`.
- Редактирование заголовка, текста, даты публикации и соцсети.
- Удаление карточки.
- Перемещение карточки только в соседнюю стадию стрелками или drag-and-drop.
- Поиск по заголовку и тексту.
- Фильтр по соцсети и состоянию даты.
- Подсветка просроченных карточек и карточек без даты в планировании.
- Отслеживание, сколько дней карточка стоит на текущей стадии.
- Фильтр зависших карточек с настраиваемым порогом в днях.
- Чеклист готовности карточки: текст, дата, проверка и ручная публикация.
- Архив опубликованных карточек с отдельным фильтром и возвратом на доску.
- AI-помощник в карточке: быстрый черновик, промпт для внешней модели и вставка в текст.
- Центр напоминаний по зависшим, просроченным и недооформленным карточкам с копированием, email и Telegram-share.
- Календарь ближайших публикаций с быстрым переходом к карточке.
- Статистика процесса: доля публикаций, средняя готовность, зависшие карточки и узкое место.
- Шаблоны карточек для обучающего поста, кейса, анонса и вопроса аудитории.
- Настройки проекта: название доски, описание, каналы, дефолтная соцсеть и порог зависания.
- История карточки: создание, редактирование, перемещение по стадиям, архив и возврат.
- Копирование списка карточек с учетом текущих фильтров.
- Экспорт и импорт JSON-бэкапа доски.
- Сохранение данных в `localStorage`, без сервера и базы данных.

## Что не входит в MVP

- Реальная публикация в соцсети.
- Логин и несколько пользователей.
- Картинки, аналитика и напоминания.

## Запуск

```powershell
npm start
```

Если PowerShell блокирует `npm.ps1`, запусти так:

```powershell
npm.cmd start
```

Или двойным кликом по файлу:

```text
start-local.cmd
```

Открой в браузере:

```text
http://localhost:5173
```

## Публикация

В репозитории есть GitHub Actions workflow для GitHub Pages. После push в `main` сайт публикуется из статических файлов проекта.
