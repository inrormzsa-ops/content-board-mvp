# Content Board MVP

Минимальная веб-доска для управления контентом по стадиям:

1. Идея
2. Черновик
3. Запланировано
4. Опубликовано

## Что входит

- Добавление новой идеи через кнопку `+ Идея`.
- Редактирование заголовка, текста, даты публикации и соцсети.
- Удаление карточки.
- Перемещение карточки только в соседнюю стадию стрелками или drag-and-drop.
- Сохранение данных в `localStorage`, без сервера и базы данных.

## Что не входит в MVP

- Реальная публикация в соцсети.
- Логин и несколько пользователей.
- Картинки, аналитика и напоминания.

## Запуск

```powershell
npm start
```

Если PowerShell блокирует `npm.ps1`, запусти так:

```powershell
npm.cmd start
```

Или двойным кликом по файлу:

```text
start-local.cmd
```

Открой в браузере:

```text
http://localhost:5173
```
